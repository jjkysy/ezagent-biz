# 官网 · 战略/定位 —— AARRR 五棒

> 这是什么：为「下一个产品 = 产品官网」开启的真相源接力链的 **节点① 战略/定位**。
> 一个官网对应**多份定位**——按 AARRR 漏斗一棒一份，每份都是一句 G-a 价值主张（`docs/rh/06-操作模板库.md` §G-a）。
> 接力链总流程见 `docs/discuss/df-prd/07-定版-自举开发流程-10分钟.md`。
>
> **产品形态（贯穿全部定位）**：官网 = 一个 **loom 生成式对话页**——底部对话框，访客用自然语言描述想看什么 → 页面即时重构。引擎（builder/发布页助手/视图切换）为**平台给定底座**，文档不展开实现（参考 `loom` 项目）。线框 = 重构后页面的「基本形式/默认骨架」，文案数据驱动。
> **两个贯穿机制**：①「内容呈现形式实验」跨切面 track（`T-内容呈现形式实验.md`）——同一信息块用 视频/树图/文字/交互 哪种最好，设计成实验而非 go/no-go；②「实验判读」取代二元 drop——达标→继续 / 未达→先改方案 / 连续未达→drop。

## 一、AARRR 漏斗（含补全的两个 R）

标准 AARRR 顺序：Acquisition → Activation → **Retention → Revenue** → Referral。
首尾三棒（浏览量/试用率/转发量）已定，中间两棒为补全项。每一棒交出去的「真相源棒」= 接力链 §2 验证/运营要钦定阈值的北极星指标。

| # | 漏斗棒 | 官网语境定义（这一棒要发生什么） | 北极星候选指标（→ 接力链 §2） |
|---|---|---|---|
| A | **Acquisition 获取** | 潜在用户被投放/搜索/分享带进站 | **浏览量 / UV** |
| A | **Activation 激活** | 进站后真的活跃：浏览命中兴趣点 + 上手体验 | **试用量 / 试用率** |
| R | **Retention 留存**〔补〕 | 一次性访问 → 可持续关系：留资 / 订阅 / 再回来 | **留资率·订阅率 + N 日回访率** |
| R | **Revenue 收入**〔补〕 | 官网促成有商业价值的转化动作 | **转化率（注册/开通/预约 demo）· 付费线索量** |
| R | **Referral 推荐** | 访问者愿意把官网转发给同行 | **转发量 / 分享率** |

> **⚠ 待拍板（定位③ Retention 的解释口径）**：
> - 口径甲（本文采用）：**官网级留存** = 留资/订阅/回访，官网负责把一次性访问沉淀成可持续触达的关系。
> - 口径乙：官网不背留存，留存是产品本身的事，官网这一棒只负责**留资**把人交给后续培育。
> 两者会让 §2 的北极星指标不同（甲量「回访率」，乙只量「留资率」）。**未定 → 暂按甲。**

## 二、五条战略/定位（G-a 一句话价值主张 · A 主句式）

句式：`让<谁>在<场景>，能<达成新体验>，而不必<旧体验的痛/成本>`。
合格判据（G-a）：句子里能指认出「谁 / 新体验 / 被替代的旧成本」三要素，全队能无歧义复述。
「谁」刻意随漏斗逐棒收窄，体现一条转化链。

### 定位① · Acquisition（→ 浏览量）

> **让被投放或搜到我们的跨境小老板，在划走之前的 3 秒内就看懂「这就是解决我那个问题的东西」，而不必读一屏术语去猜它跟自己有没有关系。**

- 谁：被精准投放/自然搜索/转发带到站的、有「用 AI 降本」意识的跨境小老板
- 新体验：3 秒认出「这是给我的」→ 愿意往下看
- 被替代的旧成本：旧官网自说自话堆功能/术语，看不懂关联 → 直接划走

### 定位② · Activation（→ 试用量/率）

> **让进站浏览的访问者，能在官网里直接跑一个对得上自己场景的 demo，而不必先注册、下载或联系销售才看得到产品到底怎么用。**

- 谁：已进站、正在浏览的访问者
- 新体验：浏览中零门槛跑通一个贴合自己场景的可跑 demo
- 被替代的旧成本：旧官网只能看图文，想体验得注册/下载/找销售 → 门槛劝退

### 定位③ · Retention〔补〕（→ 留资率·订阅率 + 回访率）

> **让有兴趣但还没决定的访问者，愿意留个联系方式或订阅更新、下次还能回来看进展，而不必一关页面就和我们彻底失联。**

- 谁：体验过、有意向但尚未转化的访问者
- 新体验：低成本留下一条可持续触达的线（留资/订阅）+ 有理由回访
- 被替代的旧成本：旧官网「看完即走」，关掉就再也找不回、企业也联系不上

### 定位④ · Revenue〔补〕（→ 转化率 · 付费线索量）

> **让试用满意的访问者，能在官网上直接完成注册开通或下单，明码看清要花多少、能拿到什么，而不必走一轮来回的销售沟通才搞清价格和交付。**

- 谁：试用满意、动了付费/合作念头的访问者
- 新体验：官网内自助走完商业动作（注册开通/下单/预约），价值与价格透明
- 被替代的旧成本：旧路径要走长销售漏斗、报价不透明、来回沟通才成交

### 定位⑤ · Referral（→ 转发量）

> **让用得满意的访问者，愿意把官网转发给同行，因为转出去对方只会觉得「这有用」而不是「又来打广告」，而不必担心转发掉自己的面子。**

- 谁：用得满意 / 被某页内容打动的访问者
- 新体验：官网本身具备「值得转发、转了有面子」的形态
- 被替代的旧成本：旧官网没什么可转发的，转了像帮发广告、掉价

## 三、接进接力链（这五条 = §1 的多份定位）

每条定位是接力链 **节点① 战略/定位** 的一份交付物；交出去的「棒」正是它对应的北极星指标——下一棒 **节点② 验证/运营** 接住后把阈值钦定下来，末尾实测回收、不达标 drop。

```
定位①浏览量 ─┐
定位②试用率 ─┤
定位③留资率 ─┼─→ ② 验证/运营：逐条钦定北极星阈值 → 末尾实测回收、不达标 drop
定位④转化率 ─┤
定位⑤转发量 ─┘
```

## 四、继续往下拆

这五条是**粗粒度**定位。每条已拆成**粒度更小的价值主张**，每个叶子「可能能让（用 AI 的）研发在一个工作日内完成」（粒度已确认）。

| 定位 | 文档（已拆分 + 接力链补全中） | 叶子数 | 依赖盯点 |
|---|---|---|---|
| ① Acquisition | `01-定位①-Acquisition.md` ✅ 已走完 §1→§6 | 7（簇 A 渠道 2 + 簇 B 落地 5） | 无 |
| ② Activation | `02-定位②拆分-Activation.md`（待补全 §1→§6） | 6 | ②-B1 需后端样例接口 |
| ③ Retention | `03-定位③拆分-Retention.md`（待补全 §1→§6） | 5 | ③-B2 跨设备需账号（v0 同设备） |
| ④ Revenue | `04-定位④拆分-Revenue.md`（待补全 §1→§6） | 6 | ④-B1 注册后端 / ④-B3 支付集成 |
| ⑤ Referral | `05-定位⑤拆分-Referral.md`（待补全 §1→§6） | 4 | ⑤-B2 自动激励需账号（v0 手动） |

合计 **28 个叶子价值主张**。每个母定位走一遍接力链，**用树状写**：

```
定位 (1) → 北极星 (1) → 输入指标 (N) → 痛点 (N) → 角色/persona (N) → 功能/内容卡 (N) + 原型/页面 (N)
```

- **北极星 vs 输入指标**：北极星=结果（果）；输入指标=可拨动它的杠杆（因），尽量成公式分解；链条 痛点→角色→卡 拨动输入→抬北极星。
- **痛点（G-c 句式）夹在输入指标和角色之间**：每个输入指标被哪些痛点拖累 → 每个痛点哪些 persona 有 → 每个痛点配哪些卡+原型。先问题后方案。
- **角色层 = persona**（不是团队角色）：见 `P-用户画像-personas.md`（赵全扛/钱降本/孙集成，**待真实用户确认**）。persona = loom 受众/视角，访客自报 → 重构到对应视角。注意：persona 无关的输入指标（如到站量/发起对话率）挂「全体访客」节点。
- **§6 卡型（只两类）**：**内容卡**＝不开发、只调内容（运营/产品/设计就地改）/ **功能卡**＝需开发（研发）。对话框/builder/发布助手 = loom **底座引用，不重建**。

**线框（两层）**：`excalidraw/主界面-全局.excalidraw`（HEAD）+ 每定位局部 `excalidraw/定位X-*.excalidraw`。线框 = 重构后页面的**基本形式/默认骨架**；persona 视角 = 对默认骨架的运行时重构。

**跨切面（暂缓）**：`T-内容呈现形式实验.md`（同一信息块用 视频/树图/文字/交互 哪种最好——机制**待单独讨论**，内容卡「候选形式」先列备选不实验）。

> ① 为样板（已按 **树状 + persona** 重写完成）。②③④⑤ 同法补全。
