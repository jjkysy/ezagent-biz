# 定位⑤ 拆分 · Referral（→ 转发量 / 分享率）

> 父定位（来自 `00-战略定位-AARRR五棒.md`）：
> **让用得满意的访问者，愿意把官网转发给同行，因为转出去对方只会觉得「这有用」而不是「又来打广告」，而不必担心转发掉自己的面子。**

**拆分规则**：每个叶子仍是一句 G-a 价值主张，粒度收到 **一个（用 AI 的）研发≈1 个工作日能交付**；「建什么（≈1 天）」是粒度证据。

Referral 天然分两簇：**A 让内容值得转发**（转了有面子）与 **B 让转发动作零摩擦**（顺手就能转）。

---

## 簇 A · 值得转发的料（转了有面子）

### ⑤-A1 可转发的「有用物」
> 让满意的访问者，手里有一个本身就有用、值得分享的东西（报告/小工具/榜单），而不必转发一个纯广告页。
- 谁/新体验/旧成本：愿意分享的人 / 转的是「有用物」不是广告 / 旧站只有广告页，转了像帮发广告
- 建什么（≈1 天）：一个可分享的「有用物」页（行业小报告 / 自测工具结果页）

### ⑤-A2 个性化结果可晒
> 让试用产生结果的访问者，得到一张「我的结果」卡（带数据/成果），转出去像晒成绩而不是发广告。
- 谁/新体验/旧成本：试出结果的人 / 晒自己的成绩单 / 旧站无个性化产物可晒
- 建什么（≈1 天）：结果分享卡生成（动态 OG 图 / 可截图的结果卡）

---

## 簇 B · 零摩擦转发（顺手就能转）

### ⑤-B1 一键分享
> 让想转发的访问者，一键就能分享到微信/社媒并自带好预览，而不必复制链接再手动配图配文。
- 谁/新体验/旧成本：想转的人 / 一键带预览转出 / 旧站要自己复制链接、配图配文
- 建什么（≈1 天）：分享按钮组件（各渠道 + 预置标题/图，复用 ①-A2 的 OG 卡）

### ⑤-B2 转发有回报（裂变钩子）
> 让转发的人和被拉来的人都得到一点好处，而不必白转。
- 谁/新体验/旧成本：算回报的人 / 转发双边都有激励 / 旧站转发无回报、动力弱
- 建什么（≈1 天）：轻量推荐机制（带 ref 参数的分享链 + 双边激励登记）
- ⚠ 依赖：依赖账号/激励发放——v0 可先只埋 ref 追踪、激励手动兑现；自动发放需账号体系

---

## 粒度自检

- 4 个叶子，每个 ≈1 个 AI-研发工作日。
- ⑤-B1 复用 ①-A2 已做的 OG 分享卡，成本更低。
- ⑤-B2 v0 先「埋 ref + 手动兑现」控制在 1 天内；自动激励依赖账号（定位④），不在本棒。
